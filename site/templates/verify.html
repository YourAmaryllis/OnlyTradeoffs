Run it yourself

You don't have to trust us. Every measure page has a Verify this section with three options:

  1. Download the bundle. It contains the official text as the models received it, the value list, every prompt exactly as sent, the output schema, every model reply (including rejected ones), the reconciled result, and the scripts that produced it.
  2. Copy the prompt and paste it into any AI chat. Compare the results it returns with ours.
  3. Run the scripts with your own API keys and compare results automatically.

Compare results (which values the text supports or conflicts with, and which clauses do it), not wording. Models phrase things differently each run.

Use it on any measure, with your own AI

The same instructions are packaged for common AI apps. They walk you through getting the official text, splitting it into sections, and producing the same value-by-value results.

Download the packs

  • Claude: a skill (claude-skill/only-tradeoffs).
  • Gemini: instructions and knowledge files for a Gem.
  • ChatGPT: instructions and knowledge files for a custom GPT.
  • Any other chat (Grok, open-weights models): one self-contained prompt to paste.

Chat apps add their own hidden instructions and may not use the same model version as our runs, so results can differ. The scripts with an API key give the closest comparison.
