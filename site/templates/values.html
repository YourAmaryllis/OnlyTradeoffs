Values

Every measure is checked against this one list, and every value on it is checked every time. Each value is something some people care about. For each one, a model reports whether the text supports it, conflicts with it, does both, or neither, and quotes the words that show it.

Where people value opposite directions on the same thing, each direction is its own value, so neither is the default. A clause that supports one of these always conflicts with its mirror, and both are shown.
