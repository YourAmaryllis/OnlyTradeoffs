# Step 1 — Concerns by Perspective (labeled, audit trail only)

> **Revision 2026-10-26 (bias-review pass):** full reads of S05 and S06 added CON-22–24 and PRO-21–28; CON-21 comes from S08, which is still a search summary. See `bias-review-response.md`.

> **Tag `[strand]`:** marks a position held by a distinct strand within a perspective, not its mainstream. The entry stays on concern trails for traceability, but the coverage audit never counts it as that perspective's support.

> This file carries perspective labels because it records **where each concern came from**. Per DESIGN.md §4.2 and §5.7, it is published in the methodology repo for anyone to audit. It is **never** shown on measure pages and **never** sent to an evaluating model.

**Rule for this file:** each perspective's concerns are written the way people who hold them would put them, drawn from that perspective's own sources and not from its critics. Where a phrase is the source's own wording, it's quoted. Source IDs refer to `sources.md`.

Each entry has an ID (`CON-04`) that `concerns-v1.md` cites.
